Proxy List ×
Browsers cannot set a proxy directly. Proxies only apply when Relay URL is set — the relay forwards upstream. Direct mode ignores this list.
Relay Configuration ×
If set, all HTTP requests go through the relay. The relay adds CORS headers, forwards upstream, and supports per-request proxy selection via the X-Target-Proxy header. A ready-to-run relay script is in the technical notes.
CORS reality: cross-origin fetches only work if the target sends CORS headers, or if the browser is started with --disable-web-security. The relay solves this cleanly.
